# Roadmap

Potential features for future releases:

- Interactive threading, tie-up, and treadling editor
- Float-length analysis with warnings
- Fabric-only drawdown view
- Repeat/tile preview for larger fabric simulation
- Yarn thickness and density visualization
- Undoable color palette editor with color picker
- Compare two WIF drafts side by side
- Export PDF and print-ready drafts
- Generate WIF from common patterns
- Draft statistics: ends, picks, shafts, treadles, and floats
- Explorer thumbnails via generated SVG sidecars
- Copy draft as SVG or PNG to the clipboard
- Recent colors and reusable palette library
- Auto-fix common malformed WIF files
- Weaving-direction and shed-mode toggles
- Keyboard navigation through draft cells
- Accessibility labels and high-contrast palettes
- Configurable Markdown preview size and detail level
- Pattern gallery command using bundled samples
- Shareable standalone HTML export
